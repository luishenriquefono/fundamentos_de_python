Repositório dedicado ao registro de práticas, desafios básicos e pequenos scripts desenvolvidos durante meus estudos fundamentais em Python.

---

### 📌 Sobre este Repositório

> **Aviso:** O conteúdo deste repositório consiste em **exercícios simples de fixação e aprendizado**. Os códigos aqui presentes têm foco estritamente didático, servindo como laboratório prático para consolidar a sintaxe e a lógica básica da linguagem.

Se você está buscando projetos mais complexos, arquiteturas completas ou aplicações em produção, confira os demais repositórios fixados no meu perfil.
